FAQ
Is this app safe to install?

These are the original Class Clock APK builds, distributed here by Project Istaroth for BSIT 2-1. The APK name and installed app label may still use Class Clock until a new Android build is released. Download only if you trust this project. It uses the timetable on this site, plus class/task notifications and alarms, and installs directly rather than through the Play Store.

Play Protect says that the app needs to be scanned first.

That message is normal. Play Protect scans apps installed outside the Play Store. Review its warning before deciding whether to install the legacy Class Clock APK provided on this page.

Why is the app not available yet for iOS?

There is no iPhone build yet. The file on this page is Android only.

The app crashes / I found some bugs

Send a screenshot of it to jaxsoniancius05@gmail.com

When will this app release on Google Play?

Currently, bringing the app to Google Play Store is being considered heavily. Though, there are still some plans for the app to be developed first, therefore, it'll be released once the framework for the app is fully finished just as I envisioned it to be.

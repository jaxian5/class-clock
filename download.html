CLASS CLOCK APP

Download Class Clock

Class Clock is the phone app for BSIT 2-1. It keeps the weekly schedule, class countdown, and task deadlines on the device. Class and task pop-ups still arrive when the app is closed, including after a restart, as long as notifications and alarms stay allowed. Schedule changes, skipped classes, shifts, and no-class days are checked from the same Class Clock schedule used on this site.
